Uforiya
Every track. Every version. Every collaborator. Nothing lost.

Right now, Uforiya is a workspace for unreleased music. A song keeps every version, its stems and everyone working on it in one place, instead of a folder full of files named final_v3_REALFINAL. Producers, artists, songwriters, mix engineers and studios work on the same track from anywhere, with feedback pinned to the exact second it's about.

Where it's going

I'm building Uforiya into a full creative ecosystem: software that helps musicians make music and improves the creative process from the first idea to the final master. The workspace is the foundation. The audio tools and the Sample Organizer are the next pieces, and both are already out.

How it's built

I built Uforiya solo, foundation first: data model, permissions and file security before a single screen. The audio pipeline sits on top of that.

  • Next.js and React (TypeScript) for the app
  • Python / FastAPI worker for BPM and key analysis
  • Browser-side audio processing for the tools
  • Supabase and PostgreSQL for accounts, roles and data
  • Cloudflare R2 for audio storage, Stripe for Pro

Producers buy kits constantly, and the same samples end up in five folders under five different names. Sample Organizer scans your library, finds every exact copy, and clears them in one click while one copy of each sample always stays. How it stays safe

Deleting the wrong sample from someone's library is the one mistake this app can't make, so safety is built into the engine, not just the screen.

  • Exact byte-for-byte matching, no guessing
  • One copy of every group always survives
  • Play button on every copy before you decide
  • Removals go to quarantine, one click puts them back
  • Permanent delete is a separate, deliberate step

How it's built

A desktop app built with Electron. I also built near-duplicate detection using MFCC audio fingerprints, then turned it off: it flagged samples that sounded alike but weren't the same. Exact matches only means it never removes something you wanted.

  • Free and open source
  • No account, no login, nothing uploaded
  • Windows now, macOS next, Linux after

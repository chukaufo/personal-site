Uforiya

Every track. Every version. Every collaborator. Nothing lost.

Unreleased music usually lives in a shared folder full of files named final_v3_REALFINAL. Uforiya replaces that with tracks that know their own history: who owns them, who's on them, what each person can touch, every bounce side by side, and stems grouped under the version they belong to. Built for producers, recording artists, songwriters, mix engineers, independent labels and studios working together remotely.

What it does

Upload & auto-analysis

MP3, WAV, FLAC, AIFF and M4A. BPM, key and duration are detected on upload by a Python audio worker, so nobody types metadata by hand.

Version history

Rough idea, revised bounce, final master: every version stays under the same track, and only the owner decides which one is current.

Roles & credits

Invite by username or email. Owners, editors and listeners get exactly the access they need, with credits attached to every collaborator.

Timestamped feedback

Waveform playback in the browser with comments pinned to the second, plus stems and lyrics living alongside each track.

Private sessions Pro

Hosted rooms for studio and recording sessions: password join links, per-member roles, uploads billed to the host's storage, and a lock when the session wraps.

Share links, not attachments

Public tracks get a link that unfurls with cover art and title and plays instantly. Private tracks have no link at all.

How it's built

Solo-built, backend first. I designed the data model, storage and permission rules before writing any UI, then layered the product on top.

  • Next.js API and React frontend in TypeScript
  • Supabase / PostgreSQL for data and auth
  • Cloudflare R2 for audio and stem storage
  • Python (FastAPI) worker for audio analysis
  • Client-side audio processing for the free tools
  • Stripe for Pro subscriptions

Sample Organizer Desktop

A free, open-source Electron app that finds byte-identical samples repeated across a producer's drum kits and clears the copies. On one real library it found 443MB of duplicates across 4.5GB in about a second.

  • Matches file contents, not names, with no fuzzy guesses
  • Fully local: no account, no upload, works offline
  • Safety in the engine: one copy always survives, removals are staged and reversible
  • Incremental rescans after the first pass
